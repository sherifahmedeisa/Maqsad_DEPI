## **Maqsad SRS - User Stories** 

## _**US#1 - Provider Sign-Up**_ 

As a Provider, I’d like to sign up to the application so that I can offer my services. 

## _**US#2 - Beneficiary Sign-Up**_ 

As a Beneficiary, I’d like to sign up to the application so that I can request services. 

## _**US#3 - Provider Log In**_ 

As a Provider, I want to log in securely so that I can manage my services. 

## _**US#4 - Beneficiary Log In**_ 

As a Beneficiary, I want to log in securely so that I can manage my requests. 

## _**US#5 - Create RFP**_ 

As a Client, I want to create an RFP so that I can receive proposals. 

## _**US#6 - Edit/Delete RFP**_ 

As a Client, I want to edit or delete my RFP before its deadline. 

## _**US#7 - View RFP Status**_ 

As a Client, I want to see the status of my RFPs. 

## _**US#8 - Browse RFPs**_ 

As a Service Provider, I want to browse RFPs matching my expertise. 

## _**US#9 - Submit Proposal**_ 

As a Service Provider, I want to submit proposals to RFPs. 

## _**US#10 - Prevent Duplicate Proposal**_ 

As a Service Provider, I want the system to prevent duplicate submissions. 

## _**US#11 - Proposal Notification**_ 

As a Client, I want to receive notifications when proposals arrive. 

## _**US#12 - Matching RFP Notification**_ 

As a Service Provider, I want notifications about matching RFPs. 

## _**US#13 - Secure Messaging**_ 

As a User, I want secure messaging with other users. 

## _**US#14 - Client Dashboard**_ 

As a Client, I want a dashboard summarizing my activity. 

## _**US#15 - Provider Dashboard**_ 

As a Provider, I want a dashboard for proposals and opportunities. 

## _**US#16 - Manage Users**_ 

As an Admin, I want to suspend or reactivate accounts. 

## _**US#17 - Generate Reports**_ 

As an Admin, I want platform activity reports. 

## _**US#18 - Profile View Notification**_ 

As a User, I want to know who viewed my profile or RFP. 

## _**US#19 - Recent Viewers**_ 

As a User, I want to see my last 10 viewers. 

## _**US#20 - Premium Analytics**_ 

As a Premium User, I want detailed profile-view statistics. 

## _**US#24 - Registration**_ 

As a user, I want to register and create an account. 

## _**US#25 - Account Activation**_ 

As a user, I want to activate my account using a verification code. 

## _**US#26 - User Login**_ 

As a user, I want to log in using valid credentials. 

## _**US#27 - Performance**_ 

As a user, I want pages to load quickly. 

## _**US#28 - Password Recovery**_ 

As a user, I want to recover my password. 

## _**US#29 - Client RFP Creation**_ 

As a Beneficiary, I want to create and publish RFPs. 

## _**US#30 - Provider Proposal Submission**_ 

As a Provider, I want to submit proposals. 

## _**US#31 - Client Proposal Notification**_ 

As a Beneficiary, I want to be notified of new proposals.
